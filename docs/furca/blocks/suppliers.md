# Блок: suppliers — платежи поставщикам (четвёртая очередь)

Стенд волны — в задании блока (D084: базы на MUSPELHEIM, на Маке ничего).

## Назначение

Деньги, уходящие поставщикам, — самая большая дыра в P&L после зарплаты и
наличных. Блок закрывает три вещи: справочник контрагентов (чтобы траты одного
поставщика складывались, а не рассыпались по написаниям), счёт и платёж как
**разные события с разными датами**, и инбокс классификации — очередь строк, для
которых продукт не смог сам назначить статью и точку.

Спека очереди — `docs/furca/spec-suppliers.md`: сценарии, user stories, границы.

## API-контракт

**Страницы** (веб — основной интерфейс, `src/web/`):

| Путь | Кто видит | Что делает |
|---|---|---|
| `/directory/counterparties/` | все роли (правит администратор сети) | список контрагентов, поиск |
| `/directory/counterparties/new/`, `/<id>/` | администратор сети | заведение и правка, версионирование по дате |
| `/invoices/` | бухгалтер, оперативный директор, управляющий (своя точка) | счета за период: контрагент, суммы, оплачено/нет |
| `/invoices/new/`, `/<id>/` | те же | внесение счёта: контрагент, статья, точка, период учёта, дата документа |
| `/invoices/<id>/positions/` | те же | позиции счёта: таблица, сверка с бумагой, добавление (T204, своей страницей с T232) |
| `/invoices/<id>/pay/` | те же | отметка оплаты отдельным событием с собственной датой |
| `/payments/new/` | те же | оплата без счёта (мелкая покупка) |
| `/inbox/` | бухгалтер, оперативный директор | строки без статьи: сумма сверху, назначение статьи и точки прямо в списке; бумаги с точек — только ссылкой с числом ждущих |
| `/papers/`, `/papers/<id>/` | все роли партнёра (разбирает право `suppliers.classify`) | бумаги, принесённые с точек, и их разбор (T174) |

Полная карта адресов — `docs/routes.md`, здесь только адреса блока.

**HTTP** — те же коды отказа, идемпотентность и формат ошибок, что у расходов.

`Q017` (считаем ли обязательства или только оплаченное), `Q018` (авансы и оплата

## Как это ложится на уже построенное

Всё поверх `facts` и `source_documents`: оттуда идемпотентность, защита закрытого
месяца, RLS, разнесение и выгрузка.

| Событие | Чем выражено |
|---|---|
| Счёт | `source_documents (kind='invoice')` — шапка; позиции — `facts` с `document_id`, `doc_date` = дата счёта, `period` = период учёта |
| Платёж по счёту | `facts` со служебной строкой `supplier_payment` (`kind='transfer'`), в P&L не входит — расход признан счётом |
| Оплата без счёта | обычный расходный `facts` с контрагентом |
| Строка без статьи | `facts` со служебной строкой `unclassified` и пустым `expense_item_id` — в P&L видна, а не пропадает |
| Бумага с точки | `source_documents` с `handed_over_at` и без строк — в P&L её нет, пока не разобрана |
