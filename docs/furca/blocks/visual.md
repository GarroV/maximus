# Блок `visual` — визуальная основа из дизайн-системы

**Зачем этот блок существует, одной фразой:** владелец не может протестировать продукт в
текущем виде, и это блокирует приёмку всей остальной работы. Значит визуал — не украшение,
а петля обратной связи.

Дословно от владельца 2026-08-18: «нам явно надо проработать визуал, сейчас весь интерфейс
вразнобой, нечитаемый». И 2026-08-21: «визуал тоже важен, потому что в текущем варианте я
даже протестить не могу».

**Что блок отдаёт — единственный словарь оформления, которым пользуются все
остальные блоки:**

| Что | Где | Кто потребляет |
|---|---|---|
| Ядро линейки (значения, компоненты, `.sidenav`) | `static/web/dodo-ds.css`, `domain.css`, `icons.json`, `fonts/` — копии из `GarroV/forma`, правятся там | каждый экран продукта |
| Значения продукта сверх ядра | `static/web/tokens.css` | ведомость, выгрузки; целиком — печать и титул демо |
| Правила продукта | `static/web/app.css` | каждый экран продукта |
| Классы компонентов | там же | шаблоны всех блоков |
| Каркас страницы и левая панель | `templates/web/base.html`, `components/sidenav*.html` | все экраны |
| Тёмная тема | те же токены, другие значения | все экраны |

**Что блок потребляет:** эталон — папка `Дизайн-система MAXIMUS/` (26 страниц).
Он источник истины о том, что должно быть на экране (решение владельца
27.08.2026), а не спека FURCA.

**Правило, которое делает этот блок особенным:** его файлы — **общие**. Имя
класса или токена, заведённое мимо словаря, разъезжается с эталоном молча и
всплывает на чужом экране (issue #165: `ok`/`alert` против `note--ok`/
`note--warn`). Поэтому другой блок, которому нужен новый компонент, **просит**
его здесь, а не заводит у себя.

**Инвариант:** цвет, размер и отступ в шаблоне блока — это дефект, даже если он
совпал со значением токена. Проверяется сторожем словаря.


## Definition of Done блока

- [ ] Токены и компоненты совпадают с эталоном (`Дизайн-система MAXIMUS/`) —
      сверкой, а не «похоже»
- [ ] Тёмная тема живёт **теми же токенами**, другими значениями, и её можно
      включить из интерфейса, а не только значениями в файле
- [ ] Словарь классов один: имена совпадают с эталонными (issue #165 — про то,
      как они разъехались молча)
- [ ] Цвета, размеры и отступы в шаблонах блоков отсутствуют, даже совпадающие со
      значением токена; держится сторожем словаря
- [ ] Проверено **в живом браузере** на нескольких экранах и обеих темах, со
      снимками
- [ ] Владелец может пользоваться продуктом — это исходная причина блока, а не
      украшение
