# Блок: directory

## Назначение

Бухгалтер и администратор ведут справочники (сотрудники, группы, точки, юрлица,
календарь), читают правила расчёта и выдают роли, не встречая служебных кодов и
понимая, что именно сохраняет каждая кнопка. Волна визуала D097, задача T246
(issues #313, #316, #319, #320).

## Состояние

- Сделано: значения правил с единицами (`web/rule_values.py`, только для показа), реестр
  правил по эталону модуля 17 (группы слева, страницы по 40, «Код» малым шрифтом под
  названием), карточка правила и «правила страны» без `RS`/`serbia-2026`; сохранение прав
  ролей подписанными кнопками; списки справочников: сотрудники (месяц, отбор по точке и
  движению, колонки модуля 8), группы без кода, точки («Персонал / Статус / Связь с Dodo IS»),
  юрлица, календарь годом; точки в формах ролей и условий — названиями.
- Исправлено по замечанию проверки: счётчики «Персонал» и «Людей» считают только людей видимых
  регистров (`_visible_terms`); тест в `tests/test_directory.py`, красный на старом коде.
- Дальше: не осталось задач блока; остаток — в «Открыто».
