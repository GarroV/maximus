{% extends "web/base.html" %}{% load ui i18n %} {% comment %} Права ролей: сетка «право × роль», как в эталоне «Роли и права» (T233). Строки — права по группам работы, столбцы — роли. Прежде на роль была строка со списком галочек, и чтобы понять, у кого есть «Откат периода», читали все блоки подряд. Права показываются названиями действий, а не кодами: названия берутся оттуда же, откуда их берёт отказ (`web/permissions.py`), чтобы человек прочитал на экране ролей ровно то, что прочитает в отказе, если права не окажется. Форма на роль своя, и галочки столбца привязаны к ней атрибутом `form`: одна форма на всю сетку означала бы, что правка одной роли переписывает заодно и остальные — незаметно и молча. Кнопки сохранения — строкой под сеткой, по одной на столбец. Регистры — строки той же сетки, но только на чтение: их задаёт форма роли (`core/roles.py`), а не экран партнёра. {% endcomment %} {% block title %}{% translate "Права ролей" %}{% endblock %} {% block content %} {% translate "Права ролей" as page_title %} {% include "web/roles/_head.html" with title=page_title %}
