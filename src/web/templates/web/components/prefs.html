{% load ui i18n %}{% comment %} Тема и язык — две группы кнопок (вынесено из левой панели, issue #268). Живёт в двух местах: в подвале панели и на странице учётной записи. На телефоне шапка до содержимого не должна быть выше ~120 px, а шесть кнопок по 44 (физика пальца) — это целая строка шапки; поэтому на телефоне тема и язык уезжают на страницу учётной записи, куда из шапки ведёт пункт словом. Копия разметки в двух шаблонах разъехалась бы молча, отсюда один компонент. `prefs_id` — приставка к `id` подписей групп: на странице учётной записи компонент стоит дважды (панель и сама страница), и одинаковые `id` сломали бы имя группы у диктора. Смена темы и языка — формами с кнопками, а не ссылками: смена меняет состояние (cookie), ссылку пройдёт любой предзагрузчик. Разметка — как в ядре линейки (GarroV/forma, `.sidenav__prefs`): тема — капсула `role="radiogroup"` с кнопками `role="radio" aria-checked`, язык — `.langpill` с `aria-pressed`; выбранный — кнопка `type="button"`, нажатие ничего не отправляет. {% endcomment %}{% translate "Как в системе" as theme_system %}{% translate "Светлая тема" as theme_light %}{% translate "Тёмная тема" as theme_dark %}
