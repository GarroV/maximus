{% load i18n %}{% comment %} Отбор списка ссылками (T224, D081 — «никаких выпадающих списков»). Каждый ряд — подпись и значения. Выбранное значение — `span[aria-current]`, не ссылка: ссылка на текущее состояние обманывает и мышь, и клавиатуру. Кнопки «Показать» нет: нажатая ссылка и есть применённый отбор, а весь остальной отбор она несёт в адресе (`filter_links.url`). Три вида ряда, собираются в `filter_links.py`: - `choices` без `label` — период: соседние месяцы по бокам от выбранного; - `choices` с `label` — ряд вариантов (точки, регистры, оплата); - `pick_url` — вариантов много: выбранное словами, «выбрать…» ведёт на страницу выбора, «все» снимает отбор. Варианты приезжают готовыми и только из видимого роли (D023): компонент справочников не знает. Параметры: `filters`. {% endcomment %}
